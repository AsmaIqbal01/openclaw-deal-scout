# DealClaw Customer Discovery Forms

These forms are used to validate the DealClaw product with real estate agents before building.

## Pakistan Market (Urdu + English)
- **Edit URL:** https://docs.google.com/forms/d/1qpVmohYZ_G4-UNuoDTiBU4EYtgO9qDuLGdkJgT2M4d0/edit
- **Share URL:** https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform
- **Target:** Solo estate agents in DHA, Bahria Town, Gulshan, Karachi
- **Questions:** 28 questions across 5 sections
- **Language:** Bilingual — English and Urdu script

## UK Market (English only)
- **Edit URL:** https://docs.google.com/forms/d/1Qy285njgwXaA5G6MGPmAzviqm3A1TGD83EdopDgEtbk/edit
- **Share URL:** https://docs.google.com/forms/d/e/1FAIpQLSfmhtqwQ-fK11aZAItxd0RiEWG0yaOTt3cstR3Dqredpx8iaQ/viewform
- **Target:** Estate agents in London, Manchester, Birmingham, Leeds
- **Questions:** 31 questions across 5 sections
- **Language:** English only

## Scripts
- create_form.py — creates the Pakistan form
- create_form_uk.py — creates the UK form
- form_id.txt — Pakistan form ID
- form_id_uk.txt — UK form ID
